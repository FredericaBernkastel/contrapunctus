Design sketch · egui 0.36 · desktop

Contrapunctus Workbench

A sketch for the interface over contrapunctus's library half. The design problem is not the controls — the library already has them — it is that a fugue has a shape most people can hear and cannot name, and the interface has to make that shape visible before it asks anyone to change it.

The problem

Two users, one screen

Someone with no theory knows what a tune is, that it comes back, and that it moves around. They do not know dux, comes, episode, compass or what a tier is. An expert wants every one of those and the seed as well.

Two separate applications would be the easy answer and the wrong one. The sketch instead uses one layout, two densities: every control keeps its position between modes, and Advanced reveals rather than rearranges. A plain-language label sits above the parameter's real name in mono, so a beginner reads How far it travels and an expert reads middles = [4, 5, 3] on the line underneath. Nobody is lied to and nobody has to learn a second layout.

The centrepiece is the plan strip, not the score. Three lanes, one per voice, with the theme drawn solid where it sounds. It teaches what a fugue is by being looked at — you watch the tune move from voice to voice — and it is the one view where a non-expert can make a judgement worth making.

Engineering

Three things that decide how this gets built

Notation is unusually easy here, and that is not a coincidence

Drawing a staff normally means fighting a pitch representation designed for playback. This one was designed for paper: Pitch { step, alter } is a diatonic step and an accidental, so staff position is step and nothing else — no lookup, no key-signature reasoning, no enharmonic guessing. The argument §2.1 makes for the lattice turns out to be the argument for it being drawable. Noteheads, stems, accidentals and ledger lines off step; beams from the tick grid, which is already exact.

Playback is both sinks, and the synth is the default

  • A small built-in synth — cpal or rodio, a sine or triangle with a short envelope. Perhaps 120 lines. No external dependency on the user's machine, the playhead is sample-accurate, and three voices of counterpoint need nothing richer. It is the default because it is the one that always works, including in a browser.
  • System MIDI out — better sound, at the cost of needing a synth installed and configured. Beside the first rather than instead of it: the library already writes MIDI, so this is a sink, not a format.

One scheduler, two sinks, and the sample clock is the playhead. The distinction that decides which a listener wants is between hearing the fugue clearly and hearing it well — and a tool for iteration owes the first, which is why the synth is what a fresh install plays through.

Iteration speed is already there

A generate is 0.6 seconds for 27 bars. That is fast enough to recompose on release of a slider but not on drag, so: recompose on release, and keep the previous Outcome to draw while the next one runs on a worker thread. egui repaints at 60fps against whichever is current; nothing needs to block.

An edit to the plan strip need not pay even that. compose::refill regenerates one block against pinned pitches at both seams, so a span-preserving edit lands in under 100 ms and the rest of the fugue is not merely unchanged but untouched — which is what keeps this usable at five and six voices, where a whole-piece recompose would not be.

Because seed is the only source of randomness and everything else is deterministic, “Try a different one” is a genuinely cheap button and worth making the most prominent control after Compose — it is how a non-expert explores, and the one interaction that rewards having no theory at all.

Settled

Decisions, and what each one costs

QuestionDecisionWhat it means to build
ScoreStaff notation Cheap here — Pitch::step is the staff position. Clefs and accidentals want an embedded glyph subset; everything else is Painter primitives.
SubjectChosen or imported A list of the 24, plus a file import. No note editor — the largest piece of work in the whole interface, and not fugue-specific.
Plan stripEditable, as far as it can be Every gesture maps to a Layout field. Span-preserving edits refill one block in under 100 ms; span-changing ones recompose and say so.
SoundBoth A built-in synth as the default and system MIDI out beside it. One scheduler, two sinks; the sample clock is the playhead.
Four voicesShown, disabled With the reason on hover. Enables when the solver lands, and nothing else in the interface changes — which is the test of whether the boundary is in the right place.
PlatformDesktop and web Four library functions lose their &Path; the corpus compiles in behind a feature (295 kB); generation runs a block per frame instead of a thread; dialogs go through the async API that exists on both.
SettingsSaved, plan included JSON, through serde, behind an optional feature — so the measurement binary still passes through no crate and §10.5’s claim survives. A fingerprint over the notes makes “same file, same fugue” checkable instead of promised.
